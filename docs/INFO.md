#　TATEYAMA BASE 北条 基本情報

## 1. サイト概要・目的

千葉県館山市北条にある貸別荘「TATEYAMA BASE 北条」の公式Webサイト。
宿泊予約サイト兼館山市の魅力やアクティビティと連動した体験型宿泊施設としてのブランディングを行う。

### ターゲットユーザー

- 北条海岸の夕日や富士山やその他館山観光を目的とする観光客・ファミリー（子連れ含む）
- アクティビティ（海、ゴルフ、SUP、釣り、麻雀、卓球）目的の友人グループ
- 渋滞を避けた館山観光の前泊・後泊を検討する旅行者

### 施設の特徴・魅力

- 1棟貸し
- 徒歩約2分で海
- 1階ウッドデッキ
- 屋上テラス
- 4~8名まで宿泊可能
- 施設設備充実
- レンタルサービス充実（ウェットスーツ、サップ、ライフジャケット）
- 別荘アクティビティ充実（卓球、麻雀、大型テレビ）
- 周辺施設充実（コンビニ、スーパー、飲食店、マッサージ・温泉施設）
- 周辺観光地充実（館山城、沖ノ島海水浴場、安房國一宮 安房神社、大福寺 崖観音堂、館山いちご狩りセンター、鶴谷八幡宮）

### 交通アクセス

- 交通手段は車、電車、バス、高速ジェット、フェリー
- 最寄り館山駅から徒歩約9分
