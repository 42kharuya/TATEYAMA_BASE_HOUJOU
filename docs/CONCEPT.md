# CONCEPT：TATEYAMA BASE 北条（叩き台）

このドキュメントは、公式サイトの「誰に・何を約束するか」をブレないように固定するためのものです。

- **トーン**：文章/写真/デザインが与える“雰囲気”のこと（例：清潔、開放的、安心）。
- **差別化**：似た宿が多い中で「魅力」になる特徴のこと。


## ターゲット（案）

### ターゲット案A（ファミリー寄り）

- 館山観光や北条エリアを楽しみたいファミリー（子連れ含む）
- 1棟貸しで周りを気にせず過ごしたい層

### ターゲット案B（友人グループ寄り）

- アクティビティ（SUP/釣り等）目的の友人グループ
- 宿でも卓球/麻雀など“滞在そのもの”を楽しみたい層

### ターゲット案C（前泊/後泊・移動最適化寄り）

- 渋滞回避の前泊/後泊をしたい旅行者
- 車/電車など複数手段で動く層（アクセスの分かりやすさ重視）

**決定：ターゲットは A/B/C の複合（最初に強く打ち出す順番：A->B->C）**


## 提供価値（何を約束するか）

- **1棟貸し**で、グループ/家族が自分たちのペースで過ごせる
- **屋上テラス / 1階ウッドデッキ**で屋外時間を楽しめる（[docs/INFO.md](INFO.md)）
- **設備が揃っている**ので、荷物を増やさず滞在しやすい（キッチン/洗濯乾燥等。詳細は [docs/INFO.md](INFO.md)）
- **アクティビティ×滞在**（SUPレンタル等 + 卓球/麻雀等）で「泊まる以外の体験」も作れる（[docs/INFO.md](INFO.md)）


## 差別化（魅力：案）

- 海が近い（※[docs/INFO.md](INFO.md) に「徒歩約2分」記載。）
- 駅からアクセスしやすい（※[docs/INFO.md](INFO.md) に「徒歩約9分」記載。）
- 屋上/デッキ + 室内アクティビティ（卓球/麻雀/大型テレビ）を“両方”楽しめる
- レンタル（ウェットスーツ/サップ/ライフジャケット）を用意できる

**決定：差別化は上記リストの全てを採用**


## コンセプト文（1文：案）

**決定（採用）：館山観光と海のアクティビティの拠点になれる、遊びもくつろぎも揃った1棟貸し。**

（参考）
- 案1：海と街のどちらにもアクセスしやすい北条で、1棟貸しの自由な滞在を楽しめる貸別荘。
- 案2：屋上とデッキ、そして室内アクティビティまで揃った、グループで過ごしやすい館山の1棟貸し。
- 案3：館山観光とアクティビティの拠点として、気軽に“体験”を持ち帰れる貸別荘。


## トーン（3語：案）

**決定（採用）：気軽・楽しい・アクティブ**

（参考）
- 案A：清潔・開放的・安心
- 案B：上質・静けさ・余白
- 案C：気軽・楽しい・アクティブ
