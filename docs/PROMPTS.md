# PROMPTS：AI依頼テンプレ（使い回し用）

目的：毎回の依頼で前提がブレないように、コピペで使えるテンプレを用意する。

共通ルール（重要）

- 事実の厳守：根拠のない数値や断定を作らない
- 不明は「要確認」と明示する（勝手に埋めない）
- 参照ファイルを明記し、矛盾があれば質問する

参照（一次情報）

- 事実データ： [docs/FACTS.md](FACTS.md)
- 掲載文章： [docs/CONTENT.md](CONTENT.md)
- 施設の一次情報： [docs/INFO.md](INFO.md)

## 1) コピー生成（短い案を3つ→選ぶ）

用途：Heroキャッチ/見出し/CTAなど、短文コピーの案出し。

```
あなたはPM兼コピーライターです。
目的：貸別荘「TATEYAMA BASE 北条」の公式サイトMVPを1週間で公開。
制約：事実の厳守。根拠のない数値（徒歩◯分・距離など）は書かない。不明は「要確認」と明示。
参照：docs/FACTS.md、docs/CONCEPT.md、docs/COPY.md。

次のコピーを「短い案を3つ」作ってください。
- 対象（例）：Heroキャッチ / セクション見出し / CTAボタン文言
- ねらい（例）：家族向けに安心感、友人グループにワクワク感
- 禁止：数字の新規作成、誇張、断定

出力形式：
- 案1：...
- 案2：...
- 案3：...
- それぞれの意図（1行）
```

## 2) 構成レビュー（1ページLPの情報設計チェック）

用途：セクション順/導線/不足情報の指摘。

```
あなたはシニアPMです。
目的：公式サイトMVP（1ページLP）で、ユーザーが迷わず予約（外部）に進める状態を作る。
制約：事実の厳守。不明は「要確認」。
参照：docs/REQUIREMENTS.md、docs/CONTENT.md、docs/FACTS.md。

以下をレビューしてください。
1) セクション順はユーザーが知りたい順か（料金/アクセス/予約が見つけやすいか）
2) 未確定情報が混入していないか（数値/断定）
3) 予約/地図/問い合わせURLが未確定の場合の表現・無効化方針が明確か
4) 誤解を招くリスク（特に料金・トップシーズン・徒歩表記）が潰せているか

出力形式：
- 良い点（最大5つ）
- 懸念点（最大5つ）
- 直すなら優先度順に（P0/P1/P2）
- 追加で確認すべき質問（最大3つ）
```

## 3) 文章校正（誤字/表記ゆれ/断定チェック）

用途：公開前に文章の品質を上げる。

```
あなたは編集者です。
目的：公式サイトの文章を「読みやすく、誇張なく、信頼できる」状態にする。
制約：事実の厳守。新しい数値や断定は作らない。
参照：docs/FACTS.md、docs/CONTENT.md。

次の文章を校正してください。
- 誤字脱字
- 表記ゆれ（チェックイン/チェックアウト、北条海岸、Wi-Fi/Wifi など）
- 断定になっている箇所（徒歩・時間・設備の有無など）
- 読みやすさ（1文が長すぎる、主語が不明など）

出力形式：
- 修正案（原文→修正文）
- 修正理由（1行）
- 要確認の指摘（最大5つ）

対象文章：
（ここに貼り付け）
```

## 4) 事実チェック（一次情報との差分検出）

用途：サイト文言が一次情報と一致しているか機械的にチェック。

```
あなたはQA担当です。
目的：サイト掲載文が一次情報（docs/INFO.md / docs/REQUIREMENTS.md）と矛盾しないようにする。
制約：不明は推測せず「要確認」。

入力として以下を渡します：
- 一次情報：docs/INFO.md、docs/REQUIREMENTS.md
- 掲載文章：docs/CONTENT.md（またはサイト本文）

やること：
- 数値（料金、徒歩、人数）を抽出し、一次情報と一致しているか確認
- 施設設備の有無（EV、洗濯乾燥、卓球/麻雀など）がズレていないか確認
- 予約/地図/LINEのURLが未確定の場合の表現が守られているか確認

出力形式：
- 一致（OK）
- 不一致（差分と、どちらが正か）
- 要確認（一次情報に存在しない/曖昧）
```
