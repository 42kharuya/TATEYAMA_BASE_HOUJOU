# QA：公開前チェックリスト（MVP）

目的：公開前に落とし穴を潰し、MVPの受け入れ条件（docs/REQUIREMENTS.md）を満たしていることを確認する。

参照
- 要件：docs/REQUIREMENTS.md
- 情報設計：docs/IA.md
- デザイン：docs/DESIGN.md
- 事実データ：docs/FACTS.md

## 1. 表示（レスポンシブ）

- スマホ幅（375px）で崩れない
- iOS Safari / Android Chrome 相当で崩れない
- 見出し/本文が詰まりすぎない（読みやすい）

## 2. 導線（CTA/リンク）

- Hero内に予約CTAがある
- ページ下部（#booking）に予約CTAが再掲されている
- ヘッダーに「予約/料金/アクセス」が常設されている
- `#pricing` / `#access` / `#booking` のアンカー移動が機能する

### URL未設定時の挙動（必須）

- `NEXT_PUBLIC_BOOKING_URL` 未設定 → 予約ボタンは「準備中」＋クリック不可＋説明1行
- `NEXT_PUBLIC_MAP_URL` 未設定 → 地図ボタンは「準備中」＋クリック不可
- `NEXT_PUBLIC_LINE_URL` 未設定 → LINEボタンは「準備中」＋クリック不可

## 3. コンテンツ整合

- 料金/キャンセル/レンタルが docs/FACTS.md と一致
- 徒歩表記が「約」付き（例：徒歩約30秒、徒歩約9分）
- 未確定情報（アメニティ、チェックイン/アウト時刻等）を断定していない
- 誤字脱字がない

## 4. 画像/パフォーマンス

- 画像が手元写真のみ（docs/ASSETS.md から逸脱していない）
- 画像が極端に重くない（体感で遅くない）
- Hero画像が綺麗に見える（文字が埋もれない）

## 5. アクセシビリティ

- 見出し階層が正しい（h1→h2→h3…）
- 画像に `alt` が付いている（装飾画像は `alt=""`）
- Tabで主要導線に到達できる
- フォーカスリングが見える（Focus Visible）
- コントラストが不足していない

### ライトボックス（MVP要件）

- 開く：サムネイルをタップ/クリックで開く
- 閉じる：× / `Esc` / 背景クリックで閉じる
- 次へ/前へ：ボタン + `ArrowRight`/`ArrowLeft`
- フォーカストラップが効いている
- 閉じたら元サムネイルにフォーカスが戻る
- 背景スクロールが止まる

## 6. SEO（最低限）

- `title` / `description` が設定されている
- OGPが設定されている（`og:title` / `og:description` / `og:image`）
- `noindex` になっていない
